# せきや｜席替え・座席シャッフルツール

名前リストを縦×横の座席表にランダムに配置する、席替え向けの静的Webサイトです。ビルド不要で、ブラウザだけで動作します。

## ✨ 機能

- 座席グリッド設定：縦（行数）×横（列数）をそれぞれ1〜20で指定でき、座席数をリアルタイム表示します
- 名前リストを1行1人で入力するテキストエリア（貼り付け対応）
- 前後の空白は取り除き、空行は無視されます
- 同名は別々の人として扱います（名簿で同姓同名があり得るため、同じ名前を複数行入れておくと、それぞれ別の席に配置されます。同姓同名を見分けたい場合は「田中（A）」のように区別して入力してください）
- 人数をリアルタイム表示します
- 席替え（シャッフル）：名前をランダムに座席へ配置します。名前より座席が多い場合、余った席は空席として表示されます
- 前（黒板）の向き指定：上・下・左・右から選べ、結果の座席表では選んだ側に「前（黒板）」の帯を表示します。向きを変えると表示中の座席表にもそのまま反映されます
- 結果のコピーボタン：座席表の並び（行・列）を保ったテキストでコピーします。前（黒板）の位置もテキストに含まれます
- 印刷ボタン：座席表だけを印刷できます（印刷時は入力UIを隠し、座席表のみを白背景・黒文字で紙面に出します）
- 名前リストと主要設定（縦・横・前（黒板）の向き）の自動保存：入力・設定変更のたびにブラウザ（localStorage）へ保存し、次回開いたときに復元します。名簿を毎回貼り直さなくて済むようにするための機能です
- 「もう一度シャッフル」ボタン：同じ条件でもう一度配置し直します
- バリデーション（日本語メッセージ）
- 名前が座席数を超えた場合に警告し、「人数に合わせて座席を広げる」ボタンで自動でグリッドを広げられます
- 縦・横が未入力・範囲外の場合にエラーを表示します
- PWA 対応（ホーム画面に追加可能、オフラインキャッシュ）
- テーマ切り替え（ダーク既定＋ライト、手動トグルで保存されます）

## 📝 使い方

1. 縦×横で座席の並びを指定し、前（黒板）の向きを選びます。
2. 名前を1行に1人ずつ入力します（名簿などをそのまま貼り付けてもOKです）。
3. 「席替えする」を押すと、名前がランダムに座席へ配置されます。気に入らなければ「もう一度シャッフル」でやり直せます。
4. 「結果をコピー」で座席表をテキストとして共有できます。

## 🪟 Windows 版

`windows/` フォルダに、同じ仕様の Windows アプリ（.NET 8 / WinForms）があります。座席グリッド（縦×横 各1〜20）、前（黒板）の向き、空席の扱い、結果コピーのテキスト形式は Web 版と同じで、オフラインで使えます。

- ビルド: `windows/build.bat`（Windows）または `windows/build.sh` で `windows/dist/Sekiya.exe` を生成します（リリースへの exe 添付は行いません）

## 📋 技術メモ

- 素の HTML / CSS / JavaScript のみ。外部リソース・ライブラリ不使用、フォントはシステムの日本語フォントスタック。
- 純粋なロジック（名前パース、検証、シャッフル、自動拡張、結果テキスト、保存形式）は `js/seat-core.js` に分離し、`tests/` の単体テスト（`npm test`、Node 標準機能のみ）で固定しています。
- シャッフルは Fisher-Yates 方式で、名前を行優先（左上から右へ、下の行へ）の順に座席へ割り当てます。
- コピー用テキストは、セルを「 ｜ 」で区切り、空席は「（空席）」と表記します。前が上の場合は先頭行、下の場合は末尾行に「」を付け、左・右の場合は見出し行＋各行の端に「前」を付けます。
- 入力内容はブラウザ内でのみ処理され、サーバーには何も送信されません。
- Service Worker（sw.js）が同一オリジンの GET をキャッシュします（キャッシュ名: sekiya-v1）。
- 自動保存の保存キー：`sekiya-data`（テーマ用の `sekiya-theme` とは別キー）。保存内容は名前リスト・縦・横・前の向きの JSON です。復元時は値の検証（縦・横は1〜20の整数、前の向きは top/bottom/left/right、名前は文字列）を行い、不正な値は無視して初期値を使います。
- 消去手段：既存の「リストをクリア」ボタンを消去手段と連動させ、クリア時に保存データ（`sekiya-data`）も削除します。そのためクリア後に再訪すると、名前だけでなく設定も初期値（6×6・前は上）に戻ります。
- 印刷：`style.css` の `@media print` で、結果カード（.result-card）以外のカード・トップバー・ヘッダー・フッター・操作ボタン・メッセージ類を隠し、座席セルは白背景・黒枠で出すため、ダークテーマのままでも紙面では読みやすく印刷されます。
